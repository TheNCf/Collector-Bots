# Collector-Bots

## Controls
| Action            | Control                                            |
| ----------------- | -------------------------------------------------- |
| Camera Movement   | <kbd>WASD</kbd>                                    |
| Camera Rotation   | <kbd>Mouse</kbd> + <kbd>RMB</kbd>                  |
| Zoom In/Out       | <kbd>Mouse Wheel</kbd>                             |
| Place Expand Flag | <kbd>LMB</kbd> on base and <kbd>LMB</kbd> to place |
